이 빠른 시작에서는 엔드포인트를 만들고 이벤트를 게시한 뒤, 터미널에 전송 결과가 표시되는 것을 확인합니다. 예제에서는 Node.js를 사용하지만, [Python](/ko/sdks/python/overview) 및 [Go](/ko/sdks/go/overview) SDK에서도 모든 단계를 똑같이 진행할 수 있습니다.

<Prerequisites language="node" />

<Steps>
  <Step title="CLI 설치하기">
    Relaybox CLI는 Relaybox의 이벤트를 로컬 머신으로 전달하므로, 개발 중에는 공개 URL이 없어도 됩니다.

    <CodeGroup>
      ```bash macOS
      brew install relaybox/tap/relaybox
      ```

      ```bash Linux
      curl -fsSL https://relaybox.dev/install.sh | sh
      ```

      ```powershell Windows
      scoop bucket add relaybox https://github.com/relaybox/scoop-bucket
      scoop install relaybox
      ```
    </CodeGroup>

    그런 다음 로그인합니다. 브라우저가 열리고, 유효 기간이 짧은 토큰이 머신에 저장됩니다.

    ```bash
    relaybox login
    ```
  </Step>

  <Step title="이벤트 수신 시작하기">
    새 터미널을 열고, 이벤트를 포트 3000으로 전달하는 터널을 시작합니다.

    ```bash
    relaybox listen --forward-to http://localhost:3000/webhooks
    ```

    CLI가 `ep_dev_`로 시작하는 임시 엔드포인트 ID를 출력합니다. 이 터미널은 계속 열어 두세요.

    <Tip>
      아직 서버를 실행하지 않아도 괜찮습니다. 전달에 실패하더라도 CLI는 수신한 모든 이벤트를 표시합니다.
    </Tip>
  </Step>

  <Step title="API 키 설정하기">
    대시보드에서 **테스트** API 키를 복사해 환경 변수로 내보냅니다.

    ```bash
    export RELAYBOX_API_KEY="rbx_test_..."
    ```

    <ApiKeyWarning />
  </Step>

  <Step title="이벤트 게시하기">
    SDK를 설치하고 `order.paid` 이벤트를 게시합니다.

    ```bash
    npm install @relaybox/node
    ```

    <PublishEvent />

    1~2초 안에 `relaybox listen`이 실행 중인 터미널에 이벤트가 표시됩니다.
  </Step>

  <Step title="전송 로그 확인하기">
    [대시보드](https://app.relaybox.dev/events)에서 **Events**를 열면 페이로드, 모든 전송 시도, 서버가 반환한 응답을 확인할 수 있습니다.

    <Frame caption="전송 로그에는 각 시도의 상태 코드와 소요 시간이 표시됩니다.">
      <img src="/images/screenshots/delivery-log.svg" alt="1회 시도 만에 성공적으로 전송된 order.paid 이벤트를 보여 주는 Relaybox 대시보드" />
    </Frame>
  </Step>
</Steps>
