**이벤트**는 Relaybox를 구성하는 기본 단위입니다. 이벤트를 게시하면 Relaybox가 이를 저장하고 라우팅하여 전달합니다. 한 번 게시된 이벤트는 수정하거나 삭제할 수 없습니다. [재전송](/ko/api-reference/events/replay)하거나, 요금제의 보존 기간이 끝나 만료되도록 두는 것만 가능합니다.

## 이벤트의 구조 {#anatomy-of-an-event}

<EventPayload />

<ResponseField name="id" type="string" required>
  `evt_`로 시작하는 고유 식별자입니다. 이벤트를 게시하면 Relaybox가 생성합니다.
</ResponseField>

<ResponseField name="type" type="string" required>
  [이벤트 유형](#naming-event-types)입니다(예: `order.paid`). 엔드포인트는 이벤트 유형 단위로 구독합니다.
</ResponseField>

<ResponseField name="created_at" type="string" required>
  Relaybox가 이벤트를 수락한 시각입니다. UTC 기준 ISO 8601 타임스탬프 형식입니다.
</ResponseField>

<ResponseField name="ordering_key" type="string">
  선택 사항입니다. 키가 같은 이벤트는 순서대로 전달됩니다. 자세한 내용은 [순서 보장 전달](/ko/concepts/delivery/ordering)을 참고하세요.
</ResponseField>

<ResponseField name="payload" type="object" required>
  전송할 데이터입니다. 최대 256KB까지의 유효한 JSON 객체라면 무엇이든 사용할 수 있습니다.
</ResponseField>

<ResponseField name="metadata" type="object">
  최대 20개의 문자열 키-값 쌍으로, 대시보드에서 이벤트를 필터링하는 데 사용할 수 있습니다. 메타데이터는 엔드포인트로 함께 전달되지만 변환으로 수정할 수는 없습니다.

  <Expandable title="예약된 키">
    <ResponseField name="environment" type="string">
      사용한 API 키에 따라 `test` 또는 `production`으로 자동 설정됩니다.
    </ResponseField>

    <ResponseField name="source" type="string">
      자유 형식입니다. 이벤트를 게시한 서비스의 이름을 사용하는 것이 좋습니다.
    </ResponseField>
  </Expandable>
</ResponseField>

## 이벤트 유형 이름 지정 {#naming-event-types}

이벤트 유형은 점(.)으로 구분된 소문자 문자열입니다. `resource.past_tense_verb` 패턴을 권장합니다.

<CodeGroup>
  ```text Good
  order.paid
  invoice.payment_failed
  user.email_changed
  ```

  ```text Avoid
  OrderPaid          # 소문자가 아니며 점으로 구분되지 않음
  order.pay          # 이미 일어난 일이 아니라 명령처럼 들림
  orders.paid.v2     # 버전은 유형이 아닌 페이로드에 포함할 것
  ```
</CodeGroup>

<Tip>
  엔드포인트는 와일드카드를 사용해 구독할 수 있습니다. `order.*`를 구독하면 `order.paid`와 `order.refunded`는 매칭되지만 `order.line_item.added`는 매칭되지 않습니다. 모든 하위 수준까지 매칭하려면 `order.**`를 사용하세요.
</Tip>

## 크기 제한 {#size-limits}

| 필드             | 제한               |
| -------------- | ---------------- |
| `type`         | 128자             |
| `ordering_key` | 256자             |
| `payload`      | JSON 인코딩 후 256KB |
| `metadata`     | 키 20개, 값당 512자   |

이보다 큰 데이터를 보내야 한다면 직접 페이로드에 담는 대신 자체 스토리지에 업로드한 뒤 서명된 URL을 페이로드에 포함하세요.
