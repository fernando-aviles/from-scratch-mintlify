[이벤트 목록 조회](/ko/api-reference/events/list)처럼 목록을 반환하는 모든 엔드포인트는 **커서** 기반으로 페이지네이션됩니다. 각 응답에는 `next_cursor`가 포함되며, 이 값을 `cursor` 매개변수로 전달하면 다음 페이지를 가져올 수 있습니다.

```json
{
  "data": [
    { "id": "evt_2b7XqLm9TfR4", "type": "order.paid" },
    { "id": "evt_2b7XqLk3PdW8", "type": "order.created" }
  ],
  "next_cursor": "eyJpZCI6ImV2dF8yYjdYcUxrM1BkVzgifQ"
}
```

`next_cursor`가 `null`이면 마지막 페이지에 도달한 것입니다.

## SDK에서 반복 처리하기 {#iterating-in-the-sdks}

커서는 SDK가 알아서 처리합니다. 결과를 순회하기만 하면 필요할 때마다 다음 페이지를 가져옵니다.

<CodeGroup>
  ```javascript Node.js
  for await (const event of relaybox.events.list({ type: "order.*" })) {
    console.log(event.id);
  }
  ```

  ```python Python
  for event in relaybox.events.list(type="order.*"):
      print(event.id)
  ```

  ```go Go
  iter := client.Events.List(ctx, &relaybox.EventListParams{Type: "order.*"})
  for iter.Next() {
  	fmt.Println(iter.Event().ID)
  }
  if err := iter.Err(); err != nil {
  	log.Fatal(err)
  }
  ```
</CodeGroup>

<Tip>
  커서는 불투명한(opaque) 값입니다. 형식이 예고 없이 바뀔 수 있으므로 커서를 직접 디코딩하거나 생성하지 마세요.
</Tip>
