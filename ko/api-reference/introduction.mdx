Relaybox API는 REST 원칙에 따라 설계되었습니다. 요청 본문과 응답은 모두 JSON 형식이며, 표준 HTTP 상태 코드와 메서드를 사용합니다.

## 기본 URL {#base-url}

```text
https://api.relaybox.dev/v3
```

EU 또는 일본 데이터 레지던시를 사용하는 고객은 대신 다음 지역별 기본 URL을 사용합니다.

| 지역      | 기본 URL                           |
| ------- | -------------------------------- |
| 미국(기본값) | `https://api.relaybox.dev/v3`    |
| 유럽 연합   | `https://eu.api.relaybox.dev/v3` |
| 일본      | `https://jp.api.relaybox.dev/v3` |

## 직접 사용해 보기 {#try-it-out}

모든 엔드포인트 페이지에는 대화형 플레이그라운드가 있습니다. **Authorization** 필드에 **테스트** API 키를 붙여 넣으면 브라우저에서 바로 실제 요청을 보낼 수 있습니다.

<Warning>
  `rbx_live_` 키는 플레이그라운드는 물론 어떤 웹사이트에도 절대 붙여 넣지 마세요.
</Warning>

## 버전 관리 {#versioning}

메이저 버전은 URL에 포함됩니다. 같은 메이저 버전 내에서는 다음과 같이 하위 호환되는 변경만 적용합니다.

* 새 엔드포인트 추가
* 선택적 요청 매개변수 추가
* 응답에 필드 추가
* 확장 가능하다고 명시된 열거형에 새 값 추가

<Tip>
  응답에 포함된 알 수 없는 필드는 무시하도록 코드를 작성하세요. 그러면 필드나 값이 추가되더라도 통합이 깨지지 않습니다.
</Tip>
