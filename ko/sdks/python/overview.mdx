## 설치 {#install}

<CodeGroup>
  ```bash pip
  pip install relaybox
  ```

  ```bash uv
  uv add relaybox
  ```

  ```bash Poetry
  poetry add relaybox
  ```
</CodeGroup>

## 클라이언트 생성 {#create-a-client}

```python
import os
from relaybox import Relaybox

relaybox = Relaybox(os.environ["RELAYBOX_API_KEY"])
```

클라이언트는 스레드로부터 안전합니다. 애플리케이션 시작 시 한 번만 생성한 후 공유해서 사용하세요.
