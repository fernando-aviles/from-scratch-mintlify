## 설치 {#install}

<CodeGroup>
  ```bash npm
  npm install @relaybox/node
  ```

  ```bash pnpm
  pnpm add @relaybox/node
  ```

  ```bash yarn
  yarn add @relaybox/node
  ```

  ```bash bun
  bun add @relaybox/node
  ```
</CodeGroup>

이 패키지는 ESM 빌드와 CommonJS 빌드를 모두 제공하며, TypeScript 타입 정의도 포함되어 있습니다.

## 클라이언트 생성 {#create-a-client}

```typescript
import { Relaybox } from "@relaybox/node";

const relaybox = new Relaybox(process.env.RELAYBOX_API_KEY);
```

클라이언트는 하나만 생성해 재사용하세요. 클라이언트는 요청 사이에 HTTP 연결을 계속 유지합니다.
