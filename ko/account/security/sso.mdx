사용 가능 플랜: <Badge color="purple">Enterprise</Badge>

SSO를 사용하면 멤버가 Relaybox 비밀번호 대신 회사의 ID 공급자(IdP)를 통해 로그인합니다. 퇴사자를 IdP에서 비활성화하면 Relaybox에 대한 접근 권한도 함께 해제됩니다.

Relaybox는 SAML 2.0과 OpenID Connect를 지원합니다.

## SSO 설정 {#set-up-sso}

<Tabs>
  <Tab title="Okta">
    <Steps>
      <Step title="Okta에서 앱 만들기">
        Okta 관리 콘솔에서 **Applications → Browse App Catalog**로 이동한 후 **Relaybox**를 검색하고 **Add integration**을 클릭합니다.
      </Step>

      <Step title="메타데이터 URL 복사">
        **Sign On** 탭에서 **Metadata URL**을 복사합니다.
      </Step>

      <Step title="Relaybox 연결">
        Relaybox에서 **Settings → Security → 싱글 사인온**으로 이동한 후 **Okta**를 선택하고 복사한 메타데이터 URL을 붙여넣습니다.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Microsoft Entra ID">
    <Steps>
      <Step title="엔터프라이즈 애플리케이션 등록">
        Entra 관리 센터에서 **Enterprise applications → New application → Create your own application**으로 이동합니다. 이름을 &quot;Relaybox&quot;로 지정하고 **Integrate any other application you don&#39;t find in the gallery**를 선택합니다.
      </Step>

      <Step title="SAML 구성">
        **싱글 사인온**에서 **SAML**을 선택합니다. **Identifier**와 **Reply URL**에는 Relaybox의 **Settings → Security → 싱글 사인온**에 표시된 값을 입력합니다.
      </Step>

      <Step title="페더레이션 메타데이터 업로드">
        **Federation Metadata XML**을 다운로드한 후 Relaybox에 업로드합니다.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Google Workspace">
    <Steps>
      <Step title="사용자 지정 SAML 앱 추가">
        Google 관리 콘솔에서 **Apps → Web and mobile apps → Add app → Add custom SAML app**으로 이동합니다.
      </Step>

      <Step title="정보 교환">
        Google에서 IdP 메타데이터를 다운로드한 후 Relaybox에 표시된 ACS URL과 Entity ID를 입력합니다.
      </Step>

      <Step title="사용 설정">
        **User access**를 **ON for everyone**으로 설정하거나, 액세스가 필요한 조직 단위에 대해서만 사용 설정합니다.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## SSO 강제 적용 {#enforce-sso}

테스트를 마쳤으면 **Require SSO**를 켭니다. 비밀번호로 가입한 멤버는 다음 방문 시 IdP를 통해 로그인하라는 안내를 받습니다.

<Warning>
  계정 소유자는 언제든지 비밀번호와 2단계 인증으로 로그인할 수 있으므로, IdP에 장애가 발생하더라도 계정에서 잠기는 일은 없습니다. 소유자 계정에는 강력하고 고유한 비밀번호를 사용하세요.
</Warning>

## JIT(Just-in-time) 프로비저닝 {#just-in-time-provisioning}

**Just-in-time provisioning**을 켜면 IdP 인증을 통과한 모든 사용자에게 **Viewer** 역할의 Relaybox 계정이 자동으로 생성됩니다. 더 많은 권한을 부여하려면 다음과 같이 IdP 그룹을 역할에 매핑하세요:

```json
{
  "role_mappings": [
    { "idp_group": "platform-engineering", "role": "admin" },
    { "idp_group": "engineering", "role": "developer" }
  ]
}
```
