**Settings → Team**에서 멤버를 초대할 수 있습니다. 각 멤버에게는 환경별로 역할이 하나씩만 지정되므로, 예를 들어 외부 계약자에게 `test`에서는 전체 접근 권한을, `production`에서는 읽기 전용 권한만 부여할 수 있습니다.

## 역할 {#roles}

| 권한             | Viewer | Developer | Admin | Owner |
| -------------- | :----: | :-------: | :---: | :---: |
| 이벤트 및 전송 로그 조회 |    ✓   |     ✓     |   ✓   |   ✓   |
| 이벤트 재전송        |        |     ✓     |   ✓   |   ✓   |
| 엔드포인트 생성 및 편집  |        |     ✓     |   ✓   |   ✓   |
| API 키 생성       |        |           |   ✓   |   ✓   |
| 멤버 초대 및 제거     |        |           |   ✓   |   ✓   |
| 결제 관리          |        |           |       |   ✓   |
| 계정 삭제          |        |           |       |   ✓   |

<Info>
  모든 계정의 소유자는 반드시 한 명입니다. 소유권을 이전하려면 현재 소유자가 **Settings → Team**으로 이동한 뒤 해당 멤버의 메뉴를 열고 **Make owner**를 선택하면 됩니다.
</Info>

## 멤버 초대하기 {#invite-a-member}

<Steps>
  <Step title="팀 페이지 열기">
    **Settings → Team**으로 이동한 다음 **Invite member**를 클릭합니다.
  </Step>

  <Step title="역할 선택하기">
    이메일 주소를 하나 이상 입력하고(여러 개는 쉼표로 구분), 환경별로 역할을 선택합니다.
  </Step>

  <Step title="초대 보내기">
    초대는 7일이 지나면 만료됩니다. 만료된 초대는 같은 페이지에서 다시 보낼 수 있습니다.
  </Step>
</Steps>

<Tip>
  [싱글 사인온(SSO)](/ko/account/security/sso)을 활성화한 Enterprise 플랜에서는 초대 절차 없이 바로 멤버를 추가할 수 있습니다. 멤버가 ID 공급자를 통해 처음 로그인하면 계정이 자동으로 생성됩니다.
</Tip>
