API 키는 Relaybox API에 보내는 요청을 인증하는 데 사용됩니다. 각 키는 하나의 환경에 속하며, 생성할 때 단 한 번만 표시됩니다.

<ApiKeyWarning />

## 키 접두사 {#key-prefixes}

접두사를 보면 키의 용도를 알 수 있습니다.

| 접두사         | 환경   | 용도                                                                                                       |
| ----------- | ---- | -------------------------------------------------------------------------------------------------------- |
| `rbx_test_` | 테스트  | 로컬 개발 및 CI. 이벤트는 전달되지만 요금은 청구되지 않습니다.                                                                    |
| `rbx_live_` | 프로덕션 | 프로덕션 서비스                                                                                                 |
| `rbx_pub_`  | 둘 다  | 프런트엔드에 [고객 포털](/ko/guides/sending-events/fan-out#customer-portal)을 임베드할 때 사용합니다. 게시 가능 키로는 이벤트를 게시할 수 없습니다. |

## 범위 {#scopes}

새 키는 기본적으로 해당 환경에 대한 전체 액세스 권한을 가집니다. 보안을 강화하려면 각 서비스에 꼭 필요한 범위만 부여하세요.

<ParamField path="events:write" type="scope">
  이벤트를 게시합니다. 일반적으로 프로듀서 서비스에는 이 범위 하나만 있으면 됩니다.
</ParamField>

<ParamField path="events:read" type="scope">
  이벤트와 전송 시도 목록을 조회하고 개별 항목을 가져옵니다.
</ParamField>

<ParamField path="endpoints:write" type="scope">
  엔드포인트를 생성, 수정, 삭제하고 엔드포인트의 비밀 키를 교체합니다.
</ParamField>

<ParamField path="endpoints:read" type="scope">
  엔드포인트 목록을 조회하고 개별 항목을 가져옵니다. 서명 비밀 키는 포함되지 않습니다.
</ParamField>

## 키 교체 {#rotate-a-key}

키를 교체하면 권한 범위가 동일한 새 키가 생성되고, 기존 키는 삭제되도록 예약됩니다.

1. **Settings → API 키**로 이동하여 해당 키를 찾습니다.
2. **Rotate**를 클릭하고, 기존 키를 계속 사용할 기간을 즉시, 1시간, 24시간, 7일 중에서 선택합니다.
3. 새 키를 복사한 후 기존 키가 만료되기 전에 서비스에 배포합니다.

<Note>
  키가 유출된 것으로 의심되면 **Immediately**를 선택하세요. 기존 키를 사용하는 요청은 즉시 `401 unauthenticated` 오류를 반환하며 실패합니다.
</Note>
