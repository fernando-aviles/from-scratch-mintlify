소비자마다 필요한 데이터 형태가 다릅니다. 결제 서비스에는 모든 필드가 필요하지만, Slack 채널에는 한 줄 메시지면 충분합니다. 같은 이벤트를 두 번 게시하지 말고 엔드포인트에 **변환**을 연결하세요.

## 변환 작성하기 {#write-a-transformation}

변환은 `handler`라는 이름의 JavaScript 함수입니다. 이 함수는 이벤트를 받아 전송할 요청을 반환하며, 전송을 건너뛰려면 `null`을 반환하면 됩니다.

```javascript
export function handler(event) {
  // 금액이 큰 주문만 Slack에 알립니다.
  if (event.payload.amount < 100_000) {
    return null;
  }

  const dollars = (event.payload.amount / 100).toFixed(2);

  return {
    body: {
      text: `💰 New order for $${dollars} (${event.payload.order_id})`,
    },
  };
}
```

URL, 메서드, 헤더도 변경할 수 있습니다.

```javascript
export function handler(event) {
  return {
    url: `https://api.example.com/tenants/${event.metadata.tenant}/hooks`,
    headers: { "X-Event-Type": event.type },
    body: event.payload,
  };
}
```

변환에서 오류가 발생하거나 제한을 초과하면 해당 전송 시도는 실패로 처리되며, 다른 실패와 마찬가지로 재시도됩니다. 오류 메시지는 전송 로그에서 확인할 수 있습니다.

## 배포 전에 테스트하기 {#test-before-you-deploy}

대시보드 편집기에는 **Test** 패널이 있습니다. 최근 이벤트를 하나 골라 변환을 실행해 보고, 저장하기 전에 출력 결과를 확인하세요.

<Warning>
  변환은 저장하는 즉시 적용되며, 현재 재시도 대기 중인 이벤트에도 적용됩니다.
</Warning>
