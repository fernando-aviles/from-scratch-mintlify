<Update label="2026년 10월" description="v3.4" tags={["Dashboard", "SDKs"]}>
  ## 전송 로그 검색 {#delivery-log-search}

  이제 페이로드의 모든 필드로 전송 로그를 검색할 수 있습니다. **Events** 페이지의 검색 상자에 `payload.order_id:ord_8Hx2kP`를 입력해 보세요.

  ## 개선 사항 {#improvements}

  * 이제 Node.js SDK에서 Bun 1.1 이상을 지원합니다.
  * 이제 10,000개가 넘는 이벤트를 재전송하면 백그라운드에서 처리되며, 완료되면 이메일로 알려 드립니다.
  * 엔드포인트 페이지에 최근 30일간의 성공률 차트가 표시됩니다.

  ## 수정 사항 {#fixes}

  * CLI의 `listen` 명령이 24시간이 지나면 연결이 끊어질 수 있던 문제를 수정했습니다.
</Update>

<Update label="2026년 9월" description="v3.3" tags={["API"]}>
  ## 재시도 일정 사용자 지정 {#customizable-retry-schedules}

  이제 Scale 및 Enterprise 고객은 엔드포인트별로 [재시도 일정을 사용자 지정](/ko/concepts/delivery/retries#customize-the-schedule)할 수 있습니다.

  ## 개선 사항 {#improvements-2}

  * 이제 `GET /v3/events` 엔드포인트에서 `metadata`로 필터링할 수 있습니다.
  * 이제 오류 응답에 이 문서의 관련 페이지 링크인 `docs_url`이 포함됩니다.
</Update>

<Update label="2026년 8월" description="v3.2" tags={["Integrations"]}>
  ## GitHub 소스 {#github-source}

  커뮤니티에서 구축하고 관리하는 새 [GitHub 통합](/ko/guides/integrations/github)으로 Relaybox를 통해 GitHub 웹훅을 수신할 수 있습니다.

  ## 수정 사항 {#fixes-2}

  * 텍스트가 40킬로바이트를 초과하는 Slack 메시지가 이제 전송에 실패하지 않고 잘린 상태로 전송됩니다.
</Update>
