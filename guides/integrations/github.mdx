## Set up the source

1. In Relaybox, go to **Integrations → GitHub** and click **Create source**.
2. In your GitHub repository or organization, go to **Settings → Webhooks → Add webhook**.
3. Set **Payload URL** to the ingest URL from Relaybox and **Content type** to `application/json`.
4. Generate a random secret, paste it into both GitHub and Relaybox, and click **Add webhook**.

GitHub's `X-GitHub-Event` header becomes the Relaybox event type, prefixed with `github.`. A push event becomes `github.push`, and a pull request event becomes `github.pull_request`.

## Filtering by action

Many GitHub events include an `action` field — a `pull_request` event might be `opened`, `closed`, or `synchronize`. To subscribe to only some actions, turn on **Split by action** when you create the source. Event types then include the action: `github.pull_request.opened`.
