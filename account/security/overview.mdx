Relaybox handles data that's often sensitive: payment confirmations, account changes, personal information. Security is built into every layer of the platform.

## Data protection

- **In transit:** All traffic to the API and dashboard uses TLS 1.2 or later. Deliveries to your endpoints require HTTPS in production.
- **At rest:** Event payloads are encrypted with AES-256. Enterprise customers can bring their own key through AWS KMS or Google Cloud KMS.
- **Residency:** Choose to store data in the United States, the European Union, or Japan when you create an account. Data never leaves the region you choose.

## Reporting a vulnerability

If you believe you've found a security issue, email [security@relaybox.dev](mailto:security@relaybox.dev). Please don't open a public GitHub issue. We respond to every report within two business days.
