## Instalación {#install}

```bash
go get github.com/relaybox/relaybox-go/v3@latest
```

## Crear un cliente {#create-a-client}

```go
import relaybox "github.com/relaybox/relaybox-go/v3"

client := relaybox.NewClient(os.Getenv("RELAYBOX_API_KEY"))
```

Todos los métodos reciben un `context.Context` como primer argumento. Si cancelas el contexto, se cancela la solicitud, incluidos los reintentos automáticos.
