## Instalación {#install}

<CodeGroup>
  ```bash npm
  npm install @relaybox/node
  ```

  ```bash pnpm
  pnpm add @relaybox/node
  ```

  ```bash yarn
  yarn add @relaybox/node
  ```

  ```bash bun
  bun add @relaybox/node
  ```
</CodeGroup>

El paquete incluye compilaciones ESM y CommonJS, además de los tipos de TypeScript.

## Crear un cliente {#create-a-client}

```typescript
import { Relaybox } from "@relaybox/node";

const relaybox = new Relaybox(process.env.RELAYBOX_API_KEY);
```

Crea un solo cliente y reutilízalo. El cliente mantiene activas las conexiones HTTP entre una solicitud y otra.
