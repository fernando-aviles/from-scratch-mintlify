  ```bash Poetry
  poetry add relaybox
  ```

## Crear un cliente {#create-a-client}

```python
import os
from relaybox import Relaybox

relaybox = Relaybox(os.environ["RELAYBOX_API_KEY"])
```

El cliente es seguro para subprocesos (thread-safe). Créalo una sola vez al iniciar la aplicación y compártelo.
