## インストール {#install}

<CodeGroup>
  ```bash npm
  npm install @relaybox/node
  ```

  ```bash pnpm
  pnpm add @relaybox/node
  ```

  ```bash yarn
  yarn add @relaybox/node
  ```

  ```bash bun
  bun add @relaybox/node
  ```
</CodeGroup>

このパッケージには、ESM と CommonJS の両方のビルドに加えて、TypeScript の型定義が含まれています。

## クライアントを作成する {#create-a-client}

```typescript
import { Relaybox } from "@relaybox/node";

const relaybox = new Relaybox(process.env.RELAYBOX_API_KEY);
```

クライアントは1つだけ作成し、使い回してください。クライアントはリクエスト間でHTTP接続を維持します。
