  ```bash Poetry
  poetry add relaybox
  ```

## クライアントを作成する {#create-a-client}

```python
import os
from relaybox import Relaybox

relaybox = Relaybox(os.environ["RELAYBOX_API_KEY"])
```

クライアントはスレッドセーフです。起動時に一度だけ作成し、アプリケーション全体で共有してください。
