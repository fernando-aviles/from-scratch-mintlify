Relaybox が扱うデータには、決済の確認通知、アカウントの変更、個人情報など、機密性の高いものが多く含まれます。そのため、Relaybox ではプラットフォームのあらゆるレイヤーにセキュリティを組み込んでいます。

## データ保護 {#data-protection}

* **転送時:** API およびダッシュボードとの通信はすべて TLS 1.2 以降で保護されます。本番環境では、エンドポイントへの配信に HTTPS が必須です。
* **保存時:** イベントのペイロードは AES-256 で暗号化されます。Enterprise プランのお客様は、AWS KMS または Google Cloud KMS を利用して独自の暗号鍵を使用できます (BYOK)。
* **データ所在地:** アカウント作成時に、データの保存先を米国、欧州連合、日本から選択できます。データが選択したリージョンの外に出ることはありません。
