チームメンバーは **Settings → Team** から招待できます。各メンバーには環境ごとに 1 つのロールが割り当てられるため、たとえば外部の委託先に `test` ではフルアクセス、`production` では読み取り専用アクセスを付与するといった設定が可能です。

## ロール {#roles}

| 権限            | Viewer | Developer | Admin | Owner |
| ------------- | :----: | :-------: | :---: | :---: |
| イベントと配信ログの閲覧  |    ✓   |     ✓     |   ✓   |   ✓   |
| イベントの再送       |        |     ✓     |   ✓   |   ✓   |
| エンドポイントの作成と編集 |        |     ✓     |   ✓   |   ✓   |
| APIキーの作成      |        |           |   ✓   |   ✓   |
| メンバーの招待と削除    |        |           |   ✓   |   ✓   |
| 請求の管理         |        |           |       |   ✓   |
| アカウントの削除      |        |           |       |   ✓   |

<Info>
  各アカウントのオーナーは必ず1人です。オーナー権限を移譲するには、現在のオーナーが **Settings → Team** を開き、対象メンバーのメニューから **Make owner** を選択します。
</Info>

## メンバーを招待する {#invite-a-member}

<Steps>
  <Step title="チームページを開く">
    **Settings → Team** に移動し、**Invite member** をクリックします。
  </Step>

  <Step title="ロールを選択する">
    メールアドレスを 1 つ以上入力し (複数の場合はカンマで区切ります) 、環境ごとにロールを選択します。
  </Step>

  <Step title="招待を送信する">
    招待の有効期限は 7 日間です。期限切れの招待は、同じページから再送信できます。
  </Step>
</Steps>

<Tip>
  [シングルサインオン](/ja/account/security/sso)を有効にした Enterprise プランでは、招待の手順自体が不要です。メンバーは、ID プロバイダー経由で初めてサインインした時点で自動的に作成されます。
</Tip>
