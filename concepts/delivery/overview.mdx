Delivering an event sounds simple: make an HTTP request. In practice, servers time out, deploys restart processes, and networks drop packets. Relaybox's delivery engine handles these failures so you don't have to.

## What counts as a successful delivery?

A delivery attempt **succeeds** when your endpoint returns any `2xx` status code within 15 seconds. Everything else is a failure:

- `3xx` redirects (Relaybox doesn't follow redirects, for security reasons)
- `4xx` and `5xx` responses
- Timeouts, TLS errors, and DNS failures

<Tip>
  Return `2xx` as soon as you've durably stored the event, then process it asynchronously. Slow handlers are the most common cause of timeouts.
</Tip>
