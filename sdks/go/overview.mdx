## Install

```bash
go get github.com/relaybox/relaybox-go/v3@latest
```

## Create a client

```go
import relaybox "github.com/relaybox/relaybox-go/v3"

client := relaybox.NewClient(os.Getenv("RELAYBOX_API_KEY"))
```

Every method takes a `context.Context` as its first argument. Cancelling the context cancels the request, including any automatic retries.
