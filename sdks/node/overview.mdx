## Install

<CodeGroup>
```bash npm
npm install @relaybox/node
```

```bash pnpm
pnpm add @relaybox/node
```

```bash yarn
yarn add @relaybox/node
```

```bash bun
bun add @relaybox/node
```
</CodeGroup>

The package ships ESM and CommonJS builds, along with TypeScript types.

## Create a client

```typescript
import { Relaybox } from "@relaybox/node";

const relaybox = new Relaybox(process.env.RELAYBOX_API_KEY);
```

Create one client and reuse it. The client keeps HTTP connections alive between requests.
