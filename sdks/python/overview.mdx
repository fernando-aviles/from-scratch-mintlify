## Install

<CodeGroup>
```bash pip
pip install relaybox
```

```bash uv
uv add relaybox
```

```bash Poetry
poetry add relaybox
```
</CodeGroup>

## Create a client

```python
import os
from relaybox import Relaybox

relaybox = Relaybox(os.environ["RELAYBOX_API_KEY"])
```

The client is thread-safe. Create it once at startup and share it.
